## 1. D435i 已内置支持

ORB-SLAM3 **原生支持** D435i，以下资源已包含在仓库中：

| 资源类型 | 路径 | 说明 |
|:---|:---|:---|
| 配置文件 (6个) | `Examples/*/RealSense_D435i.yaml` | 各传感器模式的 YAML 配置 |
| 示例程序 | `Examples/*/*_realsense_D435i.cc` | 6 种模式的 C++ 示例 |
| 录制工具 | `Examples/Calibration/recorder_realsense_D435i.cc` | 录制数据集用于离线测试 |

编译后即可直接运行，无需额外标定。

## 2. 环境准备

### 2.1 安装 librealsense2

```bash
# 方法1：apt 安装（推荐，Ubuntu 20.04+）
sudo apt install -y librealsense2-dev librealsense2-utils

# 方法2：源码编译
git clone https://github.com/IntelRealSense/librealsense.git
cd libreansense
mkdir build && cd build
cmake ../ -DBUILD_EXAMPLES=true
make -j$(nproc)
sudo make install
```

### 2.2 验证 D435i 连接

```bash
# 查看设备信息
rs-enumerate-devices

# 实时预览（带深度）
realsense-viewer
```

### 2.3 安装 ORB-SLAM3 其他依赖

```bash
sudo apt install -y cmake g++ git libeigen3-dev libopencv-dev \
    python3 python3-numpy libboost-serialization-dev libssl-dev

# Pangolin 可视化
git clone https://github.com/stevenlovegrove/Pangolin.git
cd Pangolin && mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install
cd ../..
```

## 3. 编译 ORB-SLAM3

```bash
cd ORB_SLAM3

# 确保 librealsense2 已安装
pkg-config --modversion realsense2

# 一键编译（会自动检测 librealsense2 并编译 RealSense 相关示例）
chmod +x build.sh
./build.sh
```

编译完成后，检查 RealSense 示例是否生成：

```bash
ls -la Examples/Stereo-Inertial/stereo_inertial_realsense_D435i
ls -la Examples/RGB-D/rgbd_realsense_D435i
ls -la Examples/Monocular/mono_realsense_D435i
ls -la Examples/Monocular-Inertial/mono_inertial_realsense_D435i
ls -la Examples/RGB-D-Inertial/rgbd_inertial_realsense_D435i
ls -la Examples/Stereo/stereo_realsense_D435i
```

如果 librealsense2 没有检测到，这些程序将不会被编译。请确认 `pkg-config --modversion realsense2` 有输出版本号。

```bash
    Vocabulary/ORBvoc.txt \
    Examples/Stereo-Inertial/RealSense_D435i.yaml
```

### 4.5 单目+IMU 模式


按 **Ctrl+C** 正常退出，轨迹会自动保存。

## 5. 配置文件说明

D435i 的配置文件已内置在仓库中。以下是各文件的主要差异：

### 5.1 各模式配置文件对照

| 模式 | 配置文件 | Camera.type | IMU 参数 |
|:---|:---|:---|:---:|
| 单目 | `Monocular/RealSense_D435i.yaml` | PinHole | 无 |
| 单目+IMU | `Monocular-Inertial/RealSense_D435i.yaml` | PinHole | ✓ |
| 双目 | `Stereo/RealSense_D435i.yaml` | Rectified | 无 |
| 双目+IMU | `Stereo-Inertial/RealSense_D435i.yaml` | Rectified | ✓ |
| RGB-D | `RGB-D/RealSense_D435i.yaml` | PinHole | 无 |
| RGB-D+IMU | `RGB-D-Inertial/RealSense_D435i.yaml` | PinHole | ✓ |

### 5.2 关键参数速查

```yaml
# 双目模式（IR 相机，已校正）
Camera.type: "Rectified"
Camera1.fx: 382.613
Camera1.fy: 382.613
Camera1.cx: 320.183
Camera1.cy: 236.455
Stereo.b: 0.0499585        # 基线 ~50mm
Camera.width: 640
Camera.height: 480

# RGB-D 模式（彩色相机，针孔模型）
Camera.type: "PinHole"
Camera1.fx: 617.201
Camera1.fy: 617.362
Camera1.cx: 324.637
Camera1.cy: 242.462
RGBD.DepthMapFactor: 1000.0  # 深度值 = 原始值 / 1000

# IMU 参数（BMI055）
IMU.NoiseGyro: 1e-3
IMU.NoiseAcc: 1e-2
IMU.GyroWalk: 1e-6
IMU.AccWalk: 1e-4
IMU.Frequency: 200.0
```

### 5.3 自定义调整参数

如果需要针对自己的使用场景优化，可以修改的常用参数：

```yaml
# 特征点数量（纹理少的环境增加此值）
ORBextractor.nFeatures: 1250    # 默认 1000/1250，可调到 1500~2000

# FAST 阈值（低对比度环境降低此值）
ORBextractor.iniThFAST: 20      # 可降到 10
ORBextractor.minThFAST: 7       # 可降到 5

# 图像缩放（CPU 不够时缩小图像）
Camera.newWidth: 640            # 不设置则不缩放
Camera.newHeight: 480
```

## 6. 常见问题与调试技巧

### 6.1 初始化失败 / 长时间灰屏

**现象**: Pangolin 窗口打开但一直显示灰色，没有地图点出现。

**解决**:
- 确保 IR emitter 已关闭（代码中自动设置 `RS2_OPTION_EMITTER_ENABLED=0`）
- 移动相机时**保持平缓**，速度不要太快，同时包含旋转和平移
- 对准**纹理丰富**的区域（书架、海报、家具等，避免白墙/纯色地面）
- 对于 RGB-D 模式，确保环境光照充足

### 6.2 "No device connected"

```bash
# 检查 USB 连接
lsusb | grep -i intel

# 安装 udev 规则（源码编译 librealsense 时）
# sudo cp ~/librealsense/config/99-realsense-libusb.rules /etc/udev/rules.d/
# sudo udevadm control --reload-rules && sudo udevadm trigger
```

### 6.3 跟踪不稳定 / 容易丢失

**调整策略**:

| 策略 | 具体操作 |
|:---|:---|
| 增加特征点 | `ORBextractor.nFeatures: 1500` |
| 降低 FAST 阈值 | `iniThFAST: 10`, `minThFAST: 5` |
| 缩小图像 | `Camera.newWidth: 424`, `Camera.newHeight: 240` |
| 降低帧率 | 降低相机帧率到 15fps |
| 运动方式 | 缓慢、平稳移动，包含旋转观察纹理 |

### 6.4 USB 带宽不足

D435i 同时传输 IR 双目 + IMU 需要 USB 3.0 带宽。

```bash
# 检查 USB 控制器速度
lsusb -t
# 确保 D435i 连接到 5000M (USB 3.0) 端口
```

如果连接到 USB 2.0 (480M)，会因带宽不足导致帧率下降或数据丢失。

### 6.5 想看详细调试信息

在示例程序的 `main()` 中，SLAM 对象创建后添加：

```cpp
ORB_SLAM3::Verbose::SetTh(ORB_SLAM3::Verbose::VERBOSITY_VERBOSE);
```

需要重新编译。

### 6.6 如何录制数据集用于离线调试

```bash
# 编译并运行录制工具
cd ORB_SLAM3
# 在 CMakeLists.txt 中已包含 recorder_realsense_D435i 目标

./Examples/Calibration/recorder_realsense_D435i ./my_dataset/
```

录制后可以离线反复播放，方便调试参数。
